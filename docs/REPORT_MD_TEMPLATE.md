## 写作规范（定为标准，方便前台稳定解析）

1. **顶部必须有 YAML frontmatter**：`title`/`publisher`/`date`/`summary`/`topics`(可选 `cover`)。
   - 前台的简介卡、发布信息、标签优先从这里取，确定性最高、零猜测。
2. **正文只用一个 `#`**（报告大标题）；**`##` = 大节**（进目录）；**`###` = 子节**（目录子项）；`####` 及以下不进目录。
3. **表格用 GFM 语法**（`| ... |` + `---` 分隔行），对齐用 `:---` / `---:` / `:---:`。
4. 图片用 `![说明](URL)`；URL 建议指向 `public/reports/` 下的图或可访问外链。
5. 数值口径以原报告图表为准；正文与图表不一致时在引用块里说明取舍。

> 这份模板就是「报告解读 Markdown」的标准。离线大模型把 PDF 读完后，按此结构产出 `.md`，
> 上传到后台「报告管理 → 新增报告 → 报告解读 Markdown」即可。范例见 `public/reports/set-index-2024.md`。
