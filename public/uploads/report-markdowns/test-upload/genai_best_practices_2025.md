# 2025年中国生成式AI最佳实践：Agentic AI下的任务重构、决策与创新

## 报告速览

这份报告由**沙利文联合头豹研究院**发布，主题聚焦中国生成式AI行业的技术演进、海外案例、最佳实践评选方法，以及中国生成式AI在交通基建、金融、医疗健康、汽车、能源与工业、娱乐、企业服务、互联网等行业中的应用图谱。报告的核心判断是：生成式AI已经不只是“生成内容”的工具，而正在向**Agentic AI（代理型AI）**演进，进入更强调**自主目标、任务规划、工具调用、业务执行与结果反馈**的新阶段。

报告把生成式AI的发展放在四条主线下观察：第一，模型能力持续提升、推理成本快速下降；第二，Agentic AI成为生成式AI的下一阶段；第三，合成数据与世界模型正在帮助大模型突破数据瓶颈；第四，AI安全治理需要覆盖“数据—模型—业务”的完整链路。

## 核心结论

### 结论一：生成式AI从内容生成工具，演进为任务执行系统

报告将生成式AI演进划分为三个阶段：**Chatbot → Digital Assistant → Agentic AI**。早期Chatbot主要响应用户输入，数字助理开始理解自然语言并执行多步骤任务，而Agentic AI则进一步具备代理能力，可以围绕目标进行规划、行动、评估和优化。

==**Agentic AI的核心变化，是AI从“回答问题”进入“完成任务”。**== 它不只是被动处理输入，而是把数据、能力、程序与自主系统连接起来，在业务环境中围绕目标持续行动。

| 阶段 | 主要形态 | 核心能力 | 价值重心 |
|---|---|---|---|
| Chatbot | 聊天机器人 | 基于规则或简单模型响应文本输入 | 降低基础问答成本 |
| Digital Assistant | 数字助理 | 理解自然语言、执行多步骤任务、集成多种服务 | 提升个人与团队工作效率 |
| Agentic AI | 代理型AI / 智能体系统 | 自主设定目标、规划路径、采取行动、评估结果、迭代优化 | 重构业务流程与任务系统 |

报告同时用四个能力递进解释为什么Agentic AI是下一阶段：**被动监控、主动查询响应、事件驱动触发器、计划任务**。这意味着企业应用不再只是把AI嵌入某一个问答入口，而是需要把AI嵌入业务流程、系统工具和执行闭环。

### 结论二：模型能力提升与成本下降共同推动生成式AI普及

报告指出，人工智能相关研究持续升温，AI相关论文发表总量在2013年至2023年间翻了一番多，2023年超过**24.2万篇**；同时，前沿AI系统在严苛基准测试中的性能快速提升，推理成本也大幅下降。

### 结论三：合成数据和世界模型成为大模型迭代的新支撑

报告认为，模型训练长期依赖不断扩大的数据集，但互联网训练数据日益趋于枯竭，数据瓶颈开始成为大模型继续扩展的重要不确定性。因此，**合成数据**，尤其是由世界模型生成的数据，被视为缓解真实数据不足、降低高风险场景采集成本的重要路径。

| 概念 | 报告中的含义 | 主要价值 |
|---|---|---|
| 合成数据 | 非直接来自真实世界采集，而是通过模型、仿真或数据增强方式生成的数据 | 扩大训练样本、补充稀缺场景、降低标注与采集成本 |
| 世界模型（World Models） | 能够学习真实世界动态规律，并通过文本、图像、视频、运动数据等输入生成环境与动作模拟的生成式AI模型 | 帮助AI理解运动、力、空间关系等物理属性，用于仿真、决策与行动指导 |
| 数据增强 | 在保留关键特征的前提下修改真实数据，例如图像倾斜、混合等 | 在不完全依赖新增真实采集的前提下创造训练变化 |

报告列出合成数据的典型适用场景：**自动驾驶与机器人仿真、科学模拟及研究、游戏与VR、具身智能**。这些场景往往存在真实数据获取困难、试错成本巨大、标注成本高昂、场景复杂多变、数据标准不一致等问题。

### 结论四：AI安全治理要从单点防护走向全链路治理

报告强调，AI安全风险并不只存在于理论分析，而是真实存在于当下各种AI应用中。AI系统面临五类安全挑战：**软硬件安全、数据完整性、模型保密性、模型鲁棒性、数据隐私**；同时，模型与数据的可解释性贯穿始终。

| 风险类别 | 报告中提到的攻击或挑战 | 对应防御思路 |
|---|---|---|
| 输入与数据风险 | 闪避攻击、药饵攻击、异常数据、恶意样本 | 对抗样本检测、输入重构、输入预处理、训练数据过滤 |
| 训练与模型风险 | 后门攻击、模型污染、模型不鲁棒 | 对抗训练、网络蒸馏、DNA模型验证、模型剪枝 |
| 使用与隐私风险 | 窃取攻击、隐私泄露、输出异常 | 差分隐私、隐私聚合教师模型、模型水印、后馈检测 |
| 业务系统风险 | AI输出进入业务后造成误判或风险传导 | 前馈检测、后馈检测、熔断、冗余、安全回退 |

==**AI治理不能只在模型层做安全评估，而要在“数据进入前、模型推理中、业务调用后”连续设防。**== 报告提出的治理逻辑是：可解释数据经过前馈检测进入模型，可解释/可验证模型完成推理，输出再经过后馈检测，最终才导入业务系统。

### 结论五：最佳实践不是“模型最强”，而是“场景价值可验证”

报告提出，生成式AI最佳实践评选不是单纯比较模型参数或技术先进性，而是综合考察**功能价值、技术性能、实施支持、客户体验**。这一框架反映了生成式AI产业落地的现实要求：只有能解决明确业务问题、可部署、可维护、可持续迭代，并获得用户认可的方案，才具有最佳实践意义。

| 一级维度 | 二级关注点 | 核心判断 |
|---|---|---|
| 功能价值与适用性 | 需求适配性、核心功能完整性、场景功能泛化性 | 是否真正匹配业务目标、形成业务闭环，并具备跨场景复用能力 |
| 技术性能与创新 | 多模态融合能力、生成内容稳定性与鲁棒性、生成内容合规安全 | 是否具备复杂数据处理能力、稳定输出能力和安全合规能力 |
| 实施与支持 | 使用成本优化、智能体应用、培训与支持 | 是否能降低部署与使用门槛，并在真实流程中产生效率改善 |
| 客户体验与满意度反馈 | 场景价值、体验和定制化、满意度追踪情况 | 是否能在用户侧形成持续价值感，并推动产品迭代 |

## 方法 / 指标体系

### 数据来源与研究口径

报告说明，本市场报告所提供的生成式AI行业发展现状，来自弗若斯特沙利文咨询（中国）及头豹研究院调查。沙利文联合头豹研究院对AI基础设施行业进行了下游用户体验调查，受访者主要来自**基建、金融、医疗健康、互联网**等行业。

| 方法环节 | 报告描述 | 解读 |
|---|---|---|
| 用户体验调查 | 对AI基础设施行业下游用户开展调查 | 用于了解不同行业对生成式AI的真实需求与体验反馈 |
| 厂商案例提报 | 最佳实践评选基于各厂商向沙利文提报案例 | 案例样本具有年度与提报边界，不能等同于全市场完整排名 |
| 市场调研 | 结合行业交叉大数据与沙利文/头豹研究体系 | 用于补充案例背景、行业需求和市场变化 |
| 数据处理 | 数据采用四舍五入，小数计一位 | 解读数值时需注意精度口径 |
| 适用范围 | 仅适用于本年度中国生成式AI应用案例发展周期 | 评选结论是阶段性观察，不是永久性认证 |

> 报告特别说明：最终对最佳应用实践的评选判断基于厂商提报案例，且仅适用于本年度中国生成式AI应用案例发展周期。

### 最佳案例评选流程

报告将最佳实践评选流程概括为四步：**厂商报名、案例输入、案例评估、案例发布**。

| 阶段 | 主要动作 | 价值 |
|---|---|---|
| 01 厂商报名 | 厂商提供所处行业、联系方式等基本信息 | 建立案例池与基本参评资格 |
| 02 案例输入 | 沙利文发送调查问卷，并开展深入市场调研 | 获取案例服务情况、业务场景和用户反馈 |
| 03 案例评估 | 结合问卷调查结果与厂商沟通信息，按行业模块和评选指标评估案例服务能力 | 用统一框架比较不同行业、不同方案的落地能力 |
| 04 案例发布 | 撰写最佳案例评选内容，并与厂商透明沟通以确保内容准确 | 形成可发布、可引用、可复核的案例内容 |

### 四大评选维度

报告把评选维度分为四大类。这里最重要的是：它不是只看技术能力，而是把“业务需求、成本、交付、培训、用户满意度”都纳入判断。

| 评选维度 | 评价重点 | 具体关注 |
|---|---|---|
| 功能价值与适用性 | 能否解决业务问题 | 需求适配性、核心功能完整性、场景功能泛化性 |
| 技术性能与创新 | 技术是否可靠、先进、安全 | 多模态融合能力、生成内容稳定性与鲁棒性、生成内容合规安全 |
| 实施与支持 | 能否低成本、可持续落地 | 使用成本优化、智能体应用、培训与支持 |
| 客户体验与满意度反馈 | 用户是否真的获得价值 | 场景价值、体验和定制化、满意度追踪情况 |

## 01 生成式AI趋势洞察

### 1.1 技术优化与成本降低

报告认为，人工智能研究持续火热带来三方面变化：论文发表总量增长、前沿基准性能提升、推理成本显著下降。其背后的产业含义是：生成式AI的技术门槛和经济门槛同步下降，企业开始更容易把大模型能力嵌入实际业务。

| 指标 | 报告数据 / 判断 | 含义 |
|---|---|---|
| AI论文发表 | 2013年至2023年总数翻了一番多，2023年超过24.2万篇 | AI研究生态持续扩张 |
| 过去一年论文增长率 | **19.7%** | 生成式AI带动更广泛研究关注 |
| MMMU性能提升 | **18.8%** | 多模态/综合能力快速提升 |
| GPQA性能提升 | **48.9%** | 高难度问答推理能力提升明显 |
| SWE-bench性能提升 | **67.3%** | 软件工程任务能力快速增强 |
| GPT-3.5级别推理成本 | 2022年11月至2024年10月骤降**280多倍** | 大模型调用经济性大幅改善 |
| 硬件年化成本 | 年化成本降幅达**30%** | 底层算力成本下降 |
| 硬件能效 | 年提升率达**40%** | 单位能耗产出提高 |

### 1.2 Agentic AI创造新价值

报告把Agentic AI定义为：将大量数据、能力和程序与自主系统相结合的代理型AI。与传统生成式AI不同，它更像合作者，在业务环境中围绕目标主动行动，而不是简单遵循指令。

| Agentic AI能力 | 报告含义 | 企业落地意义 |
|---|---|---|
| 推理 | 理解目标、约束、上下文与任务关系 | 支撑复杂业务判断 |
| 感知环境 | 获取外部数据、系统状态和任务反馈 | 避免只在静态文本里工作 |
| 学习和适应 | 根据执行结果修正策略 | 形成持续优化能力 |
| 自主执行 | 独立执行复杂任务并解决问题 | 从“辅助员工”转向“承担流程环节” |

报告对Agentic AI的价值判断非常清晰：它让组织和员工获得新的效率与创造力水平，同时要求AI系统与组织目标保持一致。这也意味着，Agentic AI落地不能只依赖单个模型，而需要与业务系统、数据、权限、工具、反馈机制、治理机制共同设计。

### 1.3 合成数据推动大模型迭代与落地

报告指出，随着互联网训练数据日益枯竭，模型继续扩展面临数据瓶颈。合成数据被视为解决潜在数据短缺的重要方案，尤其适合真实数据难以采集、试错成本高、标注成本高的场景。

| 合成数据适用场景 | 原因 | 可能价值 |
|---|---|---|
| 自动驾驶 | 极端或危险场景难以真实采集 | 生成车祸、突发障碍、恶劣天气等边缘案例 |
| 机器人仿真 / 具身智能 | 真实试错成本高，物理交互复杂 | 通过模拟训练提高现实执行能力 |
| 科学模拟与工程研究 | 系统跨尺度、参数复杂 | 帮助理解和推演复杂系统 |
| 游戏与VR | 需要动态场景、物理规则与互动反馈 | 提升虚拟环境沉浸感和真实性 |

世界模型的关键在于，它不是只生成文本或图像，而是学习现实世界的动态规律。它可以理解运动、力、空间关系等物理属性，并通过生成环境及动作来模拟、指导和实施决策。因此，在自动驾驶、机器人和科学研究中，世界模型可能成为AI从“认知智能”走向“行动智能”的关键底座。

### 1.4 AI安全治理体系持续完善

报告认为，AI安全治理的挑战分布在模型全生命周期中。数据进入模型之前，需要可解释数据与前馈检测；模型自身需要可解释与可验证；推理完成后，需要后馈检测与业务反馈；最终进入业务系统前，还要有熔断、冗余和安全回退机制。

| 治理环节 | 关键机制 | 目的 |
|---|---|---|
| 数据收集阶段 | 输入预处理、训练数据过滤、可解释数据 | 防止恶意数据、异常数据、污染样本进入系统 |
| 模型训练阶段 | 对抗训练、网络蒸馏、DNA模型验证、模型剪枝 | 提升模型鲁棒性与可验证性 |
| 模型使用阶段 | 差分隐私、隐私聚合教师模型、模型水印、后馈检测 | 防止隐私泄露、模型窃取、异常输出 |
| 业务集成阶段 | 业务反馈、熔断、冗余、安全回退 | 避免AI错误判断直接冲击业务系统 |

这一框架对企业特别重要。很多组织把AI安全理解为“模型有没有敏感词过滤”或“有没有合规审核”，但报告实际上强调的是一套更完整的系统工程：AI安全既包括模型风险，也包括数据、权限、业务决策和运营流程风险。

## 03 最佳实践案例评选流程及维度解析

### 3.1 评选流程与方法

报告提出，最佳案例评选采用行业交叉大数据与全维度评估指标结合的方式，既看案例本身，也看行业背景、用户需求和实施能力。

| 评选步骤 | 具体动作 | 对评选质量的作用 |
|---|---|---|
| 厂商报名 | 提交行业与联系方式等信息 | 建立可沟通、可验证的参评对象 |
| 案例输入 | 问卷调查与市场调研同步进行 | 获得案例业务逻辑、服务内容、客户反馈 |
| 案例评估 | 根据行业模块和评选指标评估服务能力 | 降低单一维度判断偏差 |
| 案例发布 | 撰写评选内容并与厂商保持透明沟通 | 确保公开内容准确、可理解 |

### 3.2 四大维度详细解析

#### 功能价值与适用性

这一维度回答的是：产品是否真的能解决用户问题。报告将其拆成三个子项：需求适配性、核心功能完整性、场景功能泛化性。

| 子项 | 关注重点 | 解释 |
|---|---|---|
| 需求适配性 | 是否精准匹配用户业务需求和场景逻辑 | 关注目标达成、收益实现、代价考量与战略对齐 |
| 核心功能完整性 | 是否具备完整核心模块 | 包括自然语言处理、图像生成、语音交互等模块协同性与成熟度 |
| 场景功能泛化性 | 是否能适应和扩展到不同场景 | 泛化能力决定技术复用价值与长期持续性 |

#### 技术性能与创新

这一维度回答的是：技术是否足够先进、稳定、安全。报告强调，多模态融合能力、生成内容稳定性与鲁棒性、生成内容合规安全，是判断技术性能的重要标准。

| 子项 | 关注重点 | 解释 |
|---|---|---|
| 多模态融合能力 | 文本、图像、音视频等多模态数据处理与生成 | 是复杂场景智能化的核心支撑 |
| 生成内容稳定性与鲁棒性 | 不同输入条件下输出是否一致可靠 | 关注模糊指令、噪声数据、异常输入下的容错能力 |
| 生成内容合规安全 | 法律、伦理、数据安全风险 | 关注模型合规、自动化监测、合规保障与应急响应 |

#### 实施与支持

这一维度回答的是：方案是否能被客户真正用起来。报告把使用成本优化、智能体应用、培训与支持纳入评估。

| 子项 | 关注重点 | 解释 |
|---|---|---|
| 使用成本优化 | 部署、运行、维护全周期成本 | 包括硬件资源、算法迭代、人力投入、轻量化模型、云原生架构 |
| 智能体应用 | 智能体在自动化流程中的实际效果 | 关注客服、运营等场景中的响应效率与准确性 |
| 培训与支持 | 用户理解和操作门槛 | 关注持续赋能、技术支持、案例库和落地支持 |

#### 客户体验与满意度反馈

这一维度回答的是：客户是否感到有价值，以及方案是否能根据反馈不断迭代。

| 子项 | 关注重点 | 解释 |
|---|---|---|
| 场景价值 | 具体业务场景中的实际提升与收益 | 结合用户反馈和业务数据评估技术贡献 |
| 体验和定制化 | API易用性、界面直观性、参数可调、模块扩展 | 关注多系统融合和增长需求支持 |
| 满意度追踪情况 | 不同场景、不同角色的满意度 | 识别共性问题并推动产品迭代 |

### 3.3 2025重点维度：多模态融合与智能体应用

报告明确指出，2025年最佳案例评选中，在技术性能与创新维度更关注**多模态融合能力**，在实施与支持维度更关注**智能体应用情况**。

| 重点能力 | 报告中的关键要求 | 落地含义 |
|---|---|---|
| 多模态融合能力 | 模型通过统一架构同时接收和处理不同感官通道信息，把异构数据转为统一语义向量空间表示 | 企业应用需要打通文本、图像、音频、视频、时序数据等多源数据 |
| 多模态交错数据预训练 | 用多模态交错文档、双模态对应数据、特定场景数据集建立跨模态关联 | 模型训练不只是“文本续写”，而是要学会多模态语境中的关联和生成 |
| 智能体应用 | 感知与理解、任务分解与规划、工具调用与执行、反思与迭代 | AI从辅助问答进入流程执行，调用API、数据库、代码解释器、外部系统完成任务 |

报告对智能体能力的拆解非常具体：

| 智能体能力 | 具体表现 |
|---|---|
| 感知与理解 | 通过自然语言接口接收用户指令，理解语义、意图和上下文 |
| 任务分解与规划 | 将高层目标拆解为可执行子任务序列，并动态选择最优路径 |
| 工具调用与执行 | 调用API、数据库、代码解释器、外部系统等工具完成具体操作 |
| 反思与迭代 | 根据执行结果进行自我评估与修正，提升长期表现 |
| 记忆能力 | 短期记忆与长期记忆共同支持上下文理解和持续任务推进 |
| 协作方式 | 包括合作模式、竞争模式、混合模式、利己模式等多智能体关系 |

> 这一部分实际上给出了企业建设Agentic AI系统的基本蓝图：模型不是唯一核心，工具、记忆、规划、反思、协作方式和业务系统接口同样重要。

## 结语 / 启示

这份报告最重要的启示，是把生成式AI落地从“模型能力竞争”拉回到“业务系统建设”。在Agentic AI阶段，企业真正需要思考的不是“我要不要接入一个大模型”，而是：哪些业务任务可以被重新分解，哪些系统工具可以被AI调用，哪些流程可以进入自动化执行，哪些环节必须保留人工复核，哪些结果需要被持续追踪。

==**生成式AI最佳实践的核心，不是让AI多说一句话，而是让AI在真实业务中更可靠地完成一个任务。**==

对企业而言，可以从报告中提炼出三条行动建议：

| 行动方向 | 具体做法 | 对应报告依据 |
|---|---|---|
| 从场景开始，而不是从模型开始 | 先定义业务目标、收益、代价和战略对齐，再选择模型和工具 | 功能价值与适用性维度 |
| 从单点助手走向流程智能体 | 设计感知、规划、工具调用、执行、反思与迭代闭环 | Agentic AI与2025重点维度 |
| 从试点效果走向治理体系 | 建立数据、模型、业务全链路安全治理与满意度反馈机制 | AI安全治理与客户体验维度 |

如果把这份报告用于企业AI转型或公益组织数字化建设，最值得借鉴的并不是某一个具体案例，而是它的评估框架：一个AI应用是否有价值，应同时回答**业务是否适配、技术是否稳定、实施是否可持续、用户是否满意、安全是否可控**这五类问题。
